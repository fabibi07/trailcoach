## 8. ARCHITECTURE_FINDINGS

- `ImportResult.raw_files: list[RawFile]` (P0.0) nunca fue usado y no encaja con
  proveedores puros (un `RawFile` requiere el `RawStore`). `WellnessPayload`
  cubre el caso (el proveedor entrega bytes, el orquestador persiste). Propuesta:
  eliminar `raw_files` en P0.3 o redefinirlo como bytes genéricos.
- `IngestSummary.wellness` cuenta días con cualquier dato (filas o métricas),
  por eso 613 vs 605 filas `WellnessDaily`.
- Rendimiento: una importación completa toma ~8 min (≈300 descargas con pausa de
  0,5 s + parseo). Aceptable para uso manual; para sincronización automática
  conviene usar `--incremental`.
